## Source code

This project is implemented with C# and .Net. \

Write source code following the **Clean Code** principles. \
Write simple and readable code over clever code. \
If a function is too long, split it into smaller functions. \
Make sure the code does not cause CORS issues.

### Naming conventions

Source code files shall use C# casing. 

## Debugging a problem

When debugging a problem, make sure you have sufficient information to deeply understand the problem. \
If you have logs that make the source of the problem obvious, then implement a solution. \
If you are not 100% confident about the source of the problem, then:

1. reflect on 4-6 different possible sources of the problem
2. distill those down to 1-2 most likely sources
3. implement a solution for the most likely source: either adding more logging to validate your theory or implement the actual fix if you're extremely confident about the source of the problem.
